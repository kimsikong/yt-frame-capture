# YouTube Frame Capture

유튜브에서 보고 있는 그 장면을 버튼 한 번으로 **원본 해상도 그대로** 저장하는 Chrome 확장 프로그램입니다.
화면 녹화나 OS 스크린샷과 달리 자막·플레이어 UI·검은 여백이 섞이지 않고, 디코딩된 영상 프레임만 그대로 나옵니다.

## 설치

1. 이 페이지 위쪽 초록색 **Code** 버튼 → **Download ZIP** → 압축 풀기
   - 압축을 푼 폴더는 **고정된 위치**(예: `문서` 폴더)로 옮기세요. 나중에 지우거나 옮기면 확장이 멈춥니다.
2. Chrome 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드합니다** 클릭 → `manifest.json`이 바로 들어 있는 폴더 선택
5. 열려 있던 유튜브 탭은 자동으로 새로고침됩니다

처음 설치하는 분은 [GUIDE.md](GUIDE.md)에 화면별 설명과 문제 해결이 정리되어 있습니다.

## 사용법

| 동작 | 방법 |
|---|---|
| 현재 프레임 저장 | 플레이어 오른쪽 아래 **카메라 버튼 클릭** |
| 클립보드로 복사 | 카메라 버튼 **Shift + 클릭** (바로 붙여넣기) |
| 최근 캡쳐 보기 | 툴바의 확장 아이콘 클릭 |

정확한 장면을 잡으려면: **K**로 일시정지 → **,** 와 **.** 로 한 프레임씩 이동 → 카메라 버튼 클릭.
(`K` `,` `.` 는 유튜브 자체 기능입니다.)

저장 위치는 기본값 기준 `다운로드/YouTube Captures/영상제목 [영상ID] 00-03-27.480.png` 입니다.

## 설정

확장 아이콘 → **설정 열기** (또는 `chrome://extensions`의 확장 세부정보 → 확장 프로그램 옵션)

- **캡쳐 버튼**: 플레이어의 카메라 버튼 표시 여부
- **파일 형식**: PNG(무손실) / JPEG / WebP, 품질 조절
- **저장 위치와 이름**: 하위 폴더, 영상별 폴더 분리, 파일명 형식
  - 토큰: `{title}` `{id}` `{timeStr}` `{time}` `{date}` `{res}`
- **동작**: 캡쳐 시 자동 일시정지, 캡쳐 알림, 최근 기록 보관

## 해상도에 대해

캡쳐 해상도 = **그 순간 재생 중인 화질**입니다. 1080p로 보고 있으면 1920×1080이 나옵니다.
더 큰 이미지를 원하면 플레이어 설정에서 화질을 먼저 올린 뒤, 그 화질로 잠깐 재생시켜 버퍼링한 다음 캡쳐하세요.

## 한계

- **DRM 보호 영상**(유튜브 영화·대여 콘텐츠)은 브라우저가 프레임 읽기를 막습니다. 이때는 오류 알림이 뜹니다.
- 클립보드 복사는 PNG로만 동작합니다 (브라우저 제약).
- 1080p PNG 인코딩에 보통 0.1~0.3초가 걸립니다. 그 사이의 추가 입력은 무시됩니다.

## 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 정의 (MV3) |
| `content.js` | 유튜브 페이지에 주입 — 플레이어 버튼, 프레임 캡쳐, 알림 |
| `background.js` | 서비스 워커 — 다운로드 실행, 최근 기록 저장 |
| `popup.html/js` | 툴바 팝업 — 즉시 캡쳐, 최근 캡쳐 갤러리 |
| `options.html/js` | 설정 페이지 |
| `defaults.js` | 기본 설정값 (팝업·설정 페이지 공용) |
| `tools/make_icons.py` | 아이콘 PNG 생성 스크립트 (재생성 시에만 필요) |
